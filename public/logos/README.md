# Auction-house logos (calendar cover stand-ins)

Used by `AuctionCalendar.js` `HouseLogo` when a sale has no scraped cover
image. Drop `<slug>.svg` (preferred) or `<slug>.png` (transparent bg,
~400–600px wide) — no code change needed; missing files fall back to the
text mark. Slug = house name lowercased, `&`→`and`, non-alphanumerics→`-`:

antiquorum · bonhams · christies · marteau-and-co · monaco-legend ·
phillips · sothebys · watches-of-knightsbridge
